# Capture Setup

1. Open Wireshark and select the active network adapter (packets should be moving in the graph).
2. Start capture, generate the test traffic, then stop capture promptly.
3. Apply display filters after capture; examples: `http`, `dns`, `smtp`.
4. Record source/destination IP addresses, transport protocol, port numbers, and packet numbers.
5. Save the capture as a `.pcapng` file if required by the instructor.
