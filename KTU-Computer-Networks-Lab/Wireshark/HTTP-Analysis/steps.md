# HTTP Analysis

1. Begin a capture and visit a permitted **HTTP** site or local HTTP server.
2. Filter with `http` (HTTPS payload is encrypted and will not show HTTP headers).
3. Select a GET request and identify request method, URI, Host header, and TCP ports.
4. Select the response and note status code, content type, and content length.
5. Use **Follow → TCP Stream** to view the request-response exchange; capture a screenshot for the record.
