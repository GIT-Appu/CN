# Packet Tracer — Routing Configuration

For the practical exam, a topology will be provided and the required task will be one of:

- Static routing
- OSPF routing
- RIPv2 routing

Open the supplied `.pkt` topology, identify every directly connected network with `show ip interface brief`, configure the requested routing protocol on each router, and verify end-to-end connectivity with `ping` and `tracert`/`traceroute`.

See [Routing-Configuration](Routing-Configuration/README.md) for command templates. Store screenshots of successful pings and routing tables in `screenshots/`.
